11) Important rules so this does not backfire

Google’s structured data guidelines matter more than the markup itself. The schema should match visible page content, be complete and accurate, and should not claim things the page does not actually show. Rich results can be withheld even when markup is valid.

Use these rules:

Put one clear primary keyword in each title.
Keep titles human-first, not stuffed.
Make the meta description sound like a pitch, not a keyword list.
Only use FAQ schema on pages that visibly show those FAQs.
Only use Article schema on real articles.
Add canonical tags to every indexable page.
Keep one unique title and one unique description per page.
